# Kuairec-User-Growth-Analysis
This repository contains the analysis code, SQL queries, visualizations, and business insights based on the KuaiRec dataset.


## Data Availability

The raw KuaiRec dataset is not included in this repository due to file size and licensing considerations. Please download the dataset from the official KuaiRec repository.


## Research Question

How can a short-video platform improve new user activation and retention through first-day content consumption?


## Data

This project uses the KuaiRec dataset. Raw CSV files are stored locally under `data/raw/` and are not included in this repository.
